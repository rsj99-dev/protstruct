# protstruct-plot

Dependency-free Rust SVG plotting backend for protstruct.

## Build

From the `software/` directory:

```powershell
cargo build --release --manifest-path rust/protstruct_plot/Cargo.toml
```

## Modes

```text
protstruct-plot workflow --output workflow.svg
protstruct-plot consistency --input consistency.tsv --output consistency.svg
protstruct-plot mtba --input mtba.tsv --output mtba.svg
```

The `consistency` and `mtba` modes consume TSV payloads generated by
`protstruct.figure`.

Use `--lang en` or `--lang zh` to select SVG label language. The default is
English.

The backend emits SVG only and uses `Times New Roman / SimSun` font fallbacks.
It does not require matplotlib, numpy, or any other Python plotting package.
