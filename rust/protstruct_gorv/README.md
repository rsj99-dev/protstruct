# protstruct-gorv Rust core

GOR IV/V predictor using `gor5_4` (Matrix6D) and `gor5_3` (Matrix4D correction).
The model binaries are generated by:

```powershell
python software/scripts/build_gor_models.py `
  --six GOR-Algorithm-master/GOR/gor5_4cb513_W21.mod `
  --four GOR-Algorithm-master/GOR/gor5_3cb513_W21.mod `
  --out-dir software/protstruct/data
```

## Build

```powershell
cd software/rust/protstruct_gorv
cargo build --release
```

On Windows without the MSVC linker (`link.exe`), use the installed GNU toolchain:

```powershell
cargo +stable-x86_64-pc-windows-gnu build --release
```

## Run

```powershell
protstruct-gorv --model-dir ../../protstruct/data --input example.fa --output ss.fa
```

Add `--no-post` to disable isolated-residue smoothing and `--threads N` to limit
Rayon threads. The binary reads FASTA, predicts H/E/C, and writes FASTA-like
`>id` / secondary-structure records. Sequence ends (10 residues on each side)
are assigned C because GOR IV only scores complete 21-residue windows.
