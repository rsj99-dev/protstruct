# GOR model data

The compact GOR models are distributed with protstruct:

| File | Model | Size |
|---|---|---|
| `gor5_1cb513_W21.mod` | GOR V / GOR-I base, 13 positions | small text |
| `gor5_4_21.bin` | GOR IV Matrix6D, 21 positions | ~21 MB |
| `gor5_3_21.bin` | GOR IV GOR-III correction, 21 positions | ~50 KB |

The model files originate from the MIT-licensed **GOR-Algorithm** project
(Garnier–Osguthorpe–Robson implementation; see `GOR_LICENSE.txt`). The
`gor5_4`/`gor5_3` binaries are generated by:

```powershell
python software/scripts/build_gor_models.py `
  --six <path>/gor5_4cb513_W21.mod `
  --four <path>/gor5_3cb513_W21.mod `
  --out-dir software/protstruct/data
```

The source text models are not duplicated here; the distributed binaries are
sufficient for prediction. `gor5_4` is the Matrix6D main table and `gor5_3` is
the Matrix4D correction used by the GOR IV formula.
